# Russell Kestrel iOS 0.3

Rebuild of the Russell Viewer External flow for iPhone/iPad.

- 16-channel architecture (current installation: 5 cameras)
- 1/4/9/16 camera layouts
- Main/Sub stream selection
- RTSP port default 8554
- Kestrel web port default 8081
- Live RTSP player via VLCKit
- Playback search UI and Kestrel web-playback fallback
- Configurable DVR host, credentials and RTSP template
- Playback adapter isolated for the real Kestrel HDD protocol
